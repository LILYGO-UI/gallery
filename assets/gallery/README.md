# Gallery sample photos

These small images provide a repeatable visual demo for the gallery and its
packaging examples. The set intentionally includes common formats:

- `sunrise.png` and `sunrise.ppm` — warm sky and layered hills
- `forest.jpg` and `forest.ppm` — misty green forest
- `night.gif` and `night.ppm` — moonlit skyline

The PNG, JPEG, and PPM files are supported by the gallery decoder. The GIF is
included as a standard packaged sample for applications that consume the
asset set directly.

To render the demo screens locally, set `LILYGO_GALLERY_RENDER_SAMPLE_DIR` to
this directory before running `gallery-render-ui`.
